# _archive/ — criterio

Derivados de mantenimiento que NO son parte del setup ni de la investigación
refinada de `docs/`: auditorías de la documentación, prompts operativos
derivados de RFDs (`PROMPT-*.md`) e investigación previa de referencia
histórica. Regla: si un agente lo necesita para operar, NO va aquí; si un doc
de `docs/` lo cita como fuente, tampoco. Se poda sin ceremonia cuando deja de
servir (git conserva la historia).
